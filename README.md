## Featured Projects

### 🛡️ [VoxShield](https://voxshield.runs-on.dev)

**Team Innovexa · Smart India Hackathon 2026 (PS 26104)** — real-time detection of AI voice-cloning impersonation in phone calls, fully offline.

- **Mobile:** Android app (Kotlin + Jetpack Compose) running RawNet2 anti-spoofing and ECAPA-TDNN speaker verification on-device via ONNX Runtime; no audio leaves the phone.
- **Console:** FastAPI service with a precondition gate, risk profiles and an audit chain; returns `LOW_CONFIDENCE` with a reason instead of guessing.

🌐 **Site:** [voxshield.runs-on.dev](https://voxshield.runs-on.dev) · [source](https://github.com/mayur393/Voxshield_web)

### 🌾 [YieldIQ](https://github.com/mayur393/Yieldiq)

An AI-powered precision agriculture platform. Uses **Next.js**, **Supabase**, and **Google Gemini/Genkit** to generate crop strategies, harvest forecasts and multilingual (Hindi/Marathi/English) farm advice.

🌐 **Live:** [yieldiq-nine.vercel.app](https://yieldiq-nine.vercel.app)

### 🏡 [GaavConnect](https://github.com/mayur393/GaavConnect)

A Marathi-first app for village services. **React + Vite** frontend, **Express + MongoDB** backend, phone-OTP and Google sign-in with JWT sessions.
